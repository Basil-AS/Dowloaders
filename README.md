## Расширение для Chrome и Firefox (`extension/`)

Сохраняет текущую страницу в **TXT / Markdown / JSON**. Версия 3.1. Стек: WXT + TypeScript + Preact, Manifest V3 (один код для Chrome и Firefox), Vitest + Playwright.

| Площадка | Что берёт |
|---|---|
| Хабр (статьи, новости) | статья + дерево комментариев (API Хабра) |
| Reddit | пост + дерево комментариев (JSON; при 403 разбор открытой страницы, раскрытие «ещё ответы») |
| 4PDA | тема форума (5 потоков, повторы при 503, дедупликация), цитаты, код, спойлеры |
| Discourse (ntc.party и любой форум на этом движке) | вся тема через `/t/{id}.json` + `posts.json`, цитаты, ответы, лайки, теги |
| Любой другой сайт | основной текст статьи (как режим чтения), отключается в настройках |

**Экономия токенов.** По умолчанию вывод компактный: без разделителей, одна строка шапки (автор, дата, рейтинг), номер сообщения один раз (только в темах форумов), даты сжаты («2024-05-01 10:00», в пределах дня только время), вложенность комментариев — префикс `>`, пустые строки внутри сообщений схлопнуты, JSON без отступов. Ссылки на свой сайт пишутся как `/путь`, база объявлена в шапке один раз; трекинговые метки (`utm_*`, `fbclid`…) убираются. Цитаты по умолчанию сводятся к имени автора (текст уже есть выше). Картинки: не сохранять / только подпись / с адресом. Подробная шапка, цитаты и адреса картинок включаются в настройках.

**Оформление.** Светлая и тёмная темы. По умолчанию берутся тема и язык браузера (русский или английский), в настройках можно выбрать явно.

**Управление.** Popup: формат, комментарии, «последние N %», сохранить / копировать, все вкладки, недавние сохранения.
Страница настроек: тема, язык, что сохранять (ссылки, картинки, код, цитаты, шапка), фильтры комментариев (глубина, минимальный рейтинг), параллелизм и пауза, шаблон имени файла (`{date} {time} {site} {title} {id} {count}`), история, экспорт/импорт настроек.
Пункт контекстного меню и горячая клавиша **Alt+Shift+S**.

**Права.** Только `activeTab`: доступ к странице появляется по клику, горячей клавише или из меню. «Все вкладки» запрашивает доступ ко всем сайтам отдельно, один раз.

**Готовые сборки:** папка [`releases/`](releases/): `forum-article-saver-3.1.0-chrome.zip`, `…-firefox.zip`, `…-sources.zip` (исходники для AMO).
- Chrome / Edge / Brave: распаковать zip → `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка с `manifest.json`.
- Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → выбрать zip (до перезапуска браузера; постоянная установка требует подписи на addons.mozilla.org).

**Разработка** (`cd extension`):

```bash
npm ci
npm run dev            # Chrome с горячей перезагрузкой  (dev:firefox для Firefox)
npm run typecheck && npm test
npm run build && npm run e2e     # e2e: настоящий Chromium + моки площадок
npm run zip            # dist/*.zip для Chrome, Firefox и исходники
npm run icons          # перерисовать иконки из scripts/icons.mjs
npm run shots          # скриншоты интерфейса (4 варианта: тема × язык)
```

## ALT-X KeepAlive (`altx-keepalive/`)

Расширение для Chrome и Firefox: держит сессию на `update.altx-soft.ru` активной, пока открыта вкладка сайта (отключает клиентский 30-минутный таймер и по расписанию продлевает сессию обычным запросом). Версия 2.0: WXT + TypeScript + Preact, светлая и тёмная темы и язык по умолчанию из браузера, расписание через `alarms`, журнал, e2e на локальном HTTPS-макете сайта. Описание, установка и сборки: [`altx-keepalive/README.md`](altx-keepalive/README.md), готовые архивы: [`altx-keepalive/releases/`](altx-keepalive/releases/).
