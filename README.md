## Расширение для Chrome и Firefox (`forum-article-saver/`)

Сохраняет текущую страницу в **TXT / Markdown / JSON**. Версия 3.2. Стек: WXT + TypeScript + Preact, Manifest V3 (один код для Chrome и Firefox), Vitest + Playwright.

| Площадка | Что берёт |
|---|---|
| Хабр (статьи, новости) | статья + дерево комментариев (API Хабра) |
| Reddit | пост + дерево комментариев (JSON; при 403 разбор открытой страницы, раскрытие «ещё ответы») |
| 4PDA | тема форума (5 потоков, повторы при 503, дедупликация), цитаты, код, спойлеры |
| Discourse (ntc.party и любой форум на этом движке) | вся тема через `/t/{id}.json` + `posts.json`, цитаты, ответы, лайки, теги |
| XenForo (xdaforums.com и любой форум на этом движке) | вся тема постранично с последней страницы, цитаты, код, спойлеры; при ограничении запросов пауза, «Продолжить» вручную и «Пропустить» |
| Несколько вкладок | ограничение запросов и бан по сайту общие для всех вкладок и окон; повторный запуск в той же вкладке блокируется; пауза переживает закрытие popup |
| GitHub | **репозиторий целиком** в духе [gitingest](https://github.com/coderamp-labs/gitingest) (дерево + файлы, маски, лимит размера, оценка токенов); **issue / PR / обсуждение** со страницы; **все issues, PR или обсуждения** репозитория разом, с комментариями |
| Любой другой сайт | основной текст статьи (как режим чтения), отключается в настройках |

**Ограничения сайтов (429, бан).** Расширение не долбит сайт: пул останавливается на первой же 429 (или 403 на 4PDA), одна осторожная проба после паузы, которую просит сайт, и если ограничение осталось — пауза. Уже скачанное хранится в памяти вкладки; в popup появляются «Продолжить» (докачать только недостающее, например после смены IP) и «Сохранить, что есть». Для 4PDA темп заведомо мягкий (до 3 запросов одновременно, пауза 400 мс). То же для лимита запросов GitHub: сообщение скажет, когда он снимется.

**GitHub.** Режим выбирается в popup:
- *Репозиторий целиком*: 3 запроса к API + по запросу на каждый нужный файл (raw). По умолчанию исключены `.git`, `node_modules`, сборка, lock-файлы, `*.min.js`, картинки, шрифты, архивы, бинарники; свои маски и «только эти файлы» задаются в настройках, как и максимальный размер файла. Страница `/tree/<ветка>/<каталог>` даёт дайджест только этого каталога.
- *Эта страница*: issue или pull request (описание, комментарии; у PR ещё ревью и комментарии к коду) и обсуждение (с ответами и отметкой решения).
- *Все issues / pull requests / обсуждения*: фильтр «все / открытые / закрытые» и лимит количества. Для issues и PR хватает пары десятков запросов на сотни записей.
- **Токен** (Настройки → GitHub) нужен для закрытых репозиториев, для «всех обсуждений» (GraphQL GitHub требует вход) и поднимает лимит с 60 до 5000 запросов в час. Без токена одно обсуждение читается прямо со страницы (может быть неполным). Токен хранится только в этом браузере, читается фоновой страницей и уходит только на `api.github.com` и `raw.githubusercontent.com`; страницы сайтов его не видят. Достаточно доступа только на чтение (fine-grained: Contents, Issues, Pull requests, Discussions, Metadata).

**Экономия токенов.** По умолчанию вывод компактный: без разделителей, одна строка шапки (автор, дата, рейтинг), номер сообщения один раз (только в темах форумов), даты сжаты («2024-05-01 10:00», в пределах дня только время), вложенность комментариев — префикс `>`, пустые строки внутри сообщений схлопнуты, JSON без отступов. Ссылки на свой сайт пишутся как `/путь`, база объявлена в шапке один раз; трекинговые метки (`utm_*`, `fbclid`…) убираются. Цитаты по умолчанию сводятся к имени автора (текст уже есть выше). Картинки: не сохранять / только подпись / с адресом. Подробная шапка, цитаты и адреса картинок включаются в настройках.

**Оформление.** Светлая и тёмная темы. По умолчанию берутся тема и язык браузера (русский или английский), в настройках можно выбрать явно.

**Управление.** Popup: формат, комментарии, «последние N %», сохранить / копировать, все вкладки, недавние сохранения.
Страница настроек: тема, язык, что сохранять (ссылки, картинки, код, цитаты, шапка), фильтры комментариев (глубина, минимальный рейтинг), параллелизм и пауза, шаблон имени файла (`{date} {time} {site} {title} {id} {count}`), история, экспорт/импорт настроек.
Пункт контекстного меню и горячая клавиша **Alt+Shift+S**.

**Права.** `activeTab`: доступ к странице появляется по клику, горячей клавише или из меню. Плюс доступ к `api.github.com` и `raw.githubusercontent.com` для режимов GitHub (запросы идут только через фоновую страницу). «Все вкладки» запрашивает доступ ко всем сайтам отдельно, один раз.

**Готовые сборки:** папка [`forum-article-saver/releases/`](forum-article-saver/releases/): `forum-article-saver-3.2.0-chrome.zip`, `…-firefox.zip`, `…-sources.zip` (исходники для AMO).
- Chrome / Edge / Brave: распаковать zip → `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка с `manifest.json`.
- Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → выбрать zip (до перезапуска браузера; постоянная установка требует подписи на addons.mozilla.org).

**Разработка** (`cd forum-article-saver`):

```bash
npm ci
npm run dev            # Chrome с горячей перезагрузкой  (dev:firefox для Firefox)
npm run typecheck && npm test
npm run build && npm run e2e     # e2e: настоящий Chromium + моки площадок
npm run zip            # dist/*.zip для Chrome, Firefox и исходники
npm run icons          # перерисовать иконки из scripts/icons.mjs
npm run shots          # скриншоты интерфейса (4 варианта: тема × язык)
```

## ALT-X KeepAlive (`altx-keepalive/`)

Расширение для Chrome и Firefox: держит сессию на `update.altx-soft.ru` активной, пока открыта вкладка сайта (отключает клиентский 30-минутный таймер и по расписанию продлевает сессию обычным запросом). Версия 2.0: WXT + TypeScript + Preact, светлая и тёмная темы и язык по умолчанию из браузера, расписание через `alarms`, журнал, e2e на локальном HTTPS-макете сайта. Описание, установка и сборки: [`altx-keepalive/README.md`](altx-keepalive/README.md), готовые архивы: [`altx-keepalive/releases/`](altx-keepalive/releases/).
