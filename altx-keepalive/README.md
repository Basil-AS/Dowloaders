# ALT-X KeepAlive 2.0

Расширение для Chrome / Edge / Firefox. Держит сессию на `https://update.altx-soft.ru/` активной, пока открыта вкладка сайта, и избавляет от подтверждения каждые 30 минут.

## Что делает

- Отключает клиентский 30-минутный таймер простоя страницы (`updateClock`). При выключении расширения возвращает его и запускает штатный отсчёт.
- Раз в выбранный интервал (1, 2, 5, 10, 15, 20, 25 минут) отправляет от имени вкладки обычный `GET /default.aspx` с куками сайта. Расписание ведёт `alarms`, поэтому оно не зависит от таймеров фоновой вкладки.
- На странице входа запросы не отправляются. Если сервер сам завершил сессию (редирект на `Login.aspx`), это видно в статусе.
- Работает только на `update.altx-soft.ru`. Не читает логин, пароль и содержимое форм, ничего никуда не отправляет. Данные хранит только локально: настройки, последний статус и журнал из 12 записей.
- Серверный абсолютный срок жизни сессии не обходит. Если вкладка заморожена или выгружена браузером, запрос выполнится после её восстановления.

## Интерфейс

Popup: переключатель, статус (с цветом и текстом), время последнего запроса и ответ сервера, обратный отсчёт до следующего, интервал, «Продлить сейчас», журнал, оформление.
Тема и язык (русский / английский) по умолчанию берутся из браузера; можно выбрать явно. Значок на панели показывает «!», если нужно внимание (ошибка, сессия завершена, нужен вход, нет вкладки сайта).

## Права

`storage`, `alarms` и доступ к `https://update.altx-soft.ru/*`. Права `tabs` больше нет.

## Обновление с 1.x

Настройки (`enabled`, `intervalMinutes`) подхватываются как есть. Для Firefox id прежний (`altx-keepalive@local.invalid`).

## Установка

Готовые сборки лежат в [`releases/`](releases/): `altx-keepalive-2.0.0-chrome.zip`, `…-firefox.zip`, `…-sources.zip`.

- Chrome / Edge / Brave: распаковать zip в постоянную папку → `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка с `manifest.json`.
- Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → выбрать zip (до перезапуска браузера). Для постоянной установки пакет нужно подписать на addons.mozilla.org (unlisted-загрузка подходит).

## Разработка

Стек: WXT + TypeScript (strict) + Preact, Manifest V3, Vitest, Playwright.

```bash
npm ci
npm run dev            # Chrome с горячей перезагрузкой (dev:firefox для Firefox)
npm run typecheck && npm test
npm run build && npm run e2e    # e2e: Chromium с расширением против локального HTTPS-макета сайта
npm run zip            # dist/*.zip для Chrome и Firefox + исходники
npm run icons          # перерисовать иконки
```

E2E поднимает настоящий локальный HTTPS-сервер (хост `update.altx-soft.ru` сопоставляется с ним), поэтому проверяются реальные куки, редиректы и подмена `updateClock`.

## Безопасность

Расширение намеренно отключает защиту сайта от простоя (автоматический выход через 30 минут бездействия). Это удобно, но оставленная открытой вкладка с активной сессией остаётся авторизованной. Пользуйтесь на своём устройстве и выключайте расширение, когда оно не нужно.
